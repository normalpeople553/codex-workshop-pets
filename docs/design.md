# 设计一只会干活的小宠物

**简体中文** · [English](design.en.md)

默认角色用了终端符号 `>_` 做嘴巴，把真实工具事件变成表演。工作时身体前倾、漩涡眼转起来，两只爪子轮流砸键盘，汗滴和键帽一起飞。任务结束后用闭眼和向后回弹表现放松。

## 从静态形象开始

把 [pet.svg](../art/pet.svg) 当成画布。默认 `viewBox="0 0 148 94"`，画布底部留给桌面和键盘，上方留一点空间给炸毛、蒸汽和汗滴。

1. 先画轮廓。动物、机器人或别的形象都可以。缩到输入框旁的小尺寸看看，还能不能一眼认出它。
2. 把身体、眼睛、两只爪子和键盘拆开。独立的部件才能用不同的节奏动起来。
3. 给你的图形保留下表中的 SVG 类名。可以用 `<g class="pet-body">` 包住多条路径。导出后检查编辑器有没有重命名或删掉类名。
4. 在 [pet.css](../art/pet.css) 里给新轮廓调整 `transform-origin`。爪子拍下去时要碰到键盘，身体前倾时脸和耳朵一起动。

| SVG 类名 | 画什么 | 现有动作 |
| --- | --- | --- |
| `pet-body` | 身体或头部的主体组 | 待机呼吸，干活时前倾，完成时回弹 |
| `idle-face` | 平时的眼睛 | 待机时眨眼 |
| `effort` | 用力的表情和工作特效 | 干活时显示 |
| `paw left` 和 `paw right` | 两只爪子或两只手 | 错开半拍猛敲键盘 |
| `keyboard` | 键盘或角色手边的工具 | 随着拍打轻微震动 |
| `tail`、`sweat`、`speed-lines`、`key-sparks` | 可选的尾巴、汗滴、速度线和按键火花 | 让用力的方向和节奏更清楚 |
| `spiral-eye`、`steam`、`flying-key` | 可选的漩涡眼、蒸汽和飞出的键帽 | 用力到眼冒金星 |
| `rest-face` 和 `relief` | 完成时的表情和呼气 | 收尾时短暂出现 |

颜色直接改 SVG 的 `fill` 和 `stroke`。输入框上有多只时，预设会给同一角色做轻微色相变化。想保留原色，可以删除 CSS 里的 `hue-rotate(...)`。每只宠物会复制一次 SVG，渲染器会区分 SVG 内的 ID 和对应的渐变等引用。

## 把「很努力」做得看得见

先只做身体前扑和两只爪子交替，确定动作即使缩小也能看清。再把键盘震动对齐爪子落点，最后加汗滴和速度线。默认 `workshop-whack` 约每 0.28 秒循环一次，右爪晚半拍。你可以先把速度放慢确认落点，再把节奏调快。完成动作留一个反差，例如突然停手、仰身、闭眼呼气。

运行 `npm run preview`，检查待机、干活和收尾的动作，以及并排时的宽度。再回桌面发一条真实任务，确认开工时开始猛敲，任务完成时收尾。SVG 和 CSS 都是本地素材，使用你自己制作或有权分发的图形。
